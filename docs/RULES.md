# 规则包格式

规则包是 JSON，可在「设置 → 导入规则包」里选文件导入。

```json
{
  "id": "sample-rules",
  "name": "示例规则",
  "version": 1,
  "rules": [
    { "type": "literal", "from": "冼", "to": "显", "note": "姓氏读音" },
    { "type": "regex",   "from": "(\\d+)㎡", "to": "$1平方米", "note": "面积单位" }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 建议 | 唯一标识；重复导入会覆盖同 id 的包 |
| `name` | 建议 | 显示名 |
| `version` | 否 | 默认 1 |
| `rules[].type` | 是 | `literal` 纯文本替换，`regex` 正则替换 |
| `rules[].from` | 是 | 要匹配的内容 |
| `rules[].to` | 是 | 替换成什么；正则里可用 `$1` 引用分组 |
| `rules[].note` | 否 | 给自己看的备注 |

## 行为

- 规则**只作用于送 TTS 的文本**，正文显示不变。
- 每次开始朗读时读取一次规则包；规则指纹会进缓存 key，改了规则旧音频自动失效。
- 正则写错不会崩，那一条规则会被跳过。
- 内置规则（省略号、破折号、重复标点、百分号、摄氏度、km、kg、空白归一）始终生效。

## 常见用法

- **多音字**：`{"type":"literal","from":"重行","to":"重形"}` 这类"换成读得对的同音字"，比注音更稳。
- **单位**：`{"type":"regex","from":"(\\d+)m2","to":"$1平方米"}`
- **英文缩写**：`{"type":"literal","from":"CPU","to":"处理器"}`
- **书名里的符号**：`{"type":"literal","from":"·","to":"，"}`
