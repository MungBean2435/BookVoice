# 底部三项 + 液态玻璃开关：给 AI 的提示词

目标：底部导航先改成「书架 / 书签 / 设置」，外观照 NeriPlayer 的浮层胶囊，
并把「液态玻璃」做成设置里可开关的选项。

## 0 先定三件事

1. **依赖策略**：允许用 `haze` 这类现成背景模糊库，还是坚持手写？
   手写 = 可控但要自己处理快照、遮罩、降级；用库 = 快，但液体折射还是得自己写。
2. **minSdk**：< 31 只能做半透明磨砂，没有真模糊；= 31/32 有 `RenderEffect`；
   ≥ 33 才能上 AGSL 液态。
3. **默认开关**：建议默认关，用户手动开；省电/低内存自动禁用。

## 1 可直接粘的提示词（完整版）

```text
你是 Android Compose 工程师。把我的听书 App 底部导航改成三项：书架 / 书签 / 设置，
并给「底部液态玻璃」加一个可开关的设置项。

工程：<工程路径>；主题：<Theme.kt>；Compose/M3：<版本>；minSdk <..>。
现有底部导航在：<文件>，当前路由：<...>。

边界
- 只改导航与外观层，业务逻辑、数据层、播放器不改。
- 保留现有 mini player/播放条，放在 tab bar 之上，左右边距与 tab bar 一致（16dp）。
- 不新增依赖；如果非加不可，先停下来说明理由。
- 每步都要可编译，先给方案再动代码。

第一步：结构 + 视觉（先不碰模糊）
- 三个 tab：图标 + 10.5sp 标签；选中 primary，未选中 onSurface 72%。
- 胶囊容器：高 64dp，左右 margin 16dp，底部 margin 16dp + navigationBars inset；
  形状 50% 圆角（胶囊），阴影 18dp，0.5dp 描边（暗色 10% 白 / 亮色 70% 白）。
- 选中态：tab 背后一枚内缩 4dp 的小胶囊，200–360ms 平移；点按 haptic，不要 ripple。
- 底色先用 surfaceContainerLow；有背景图时 alpha 0.62。
- 三个 tab 各自 rememberSaveable 滚动位置，切换页面不重建。

第二步：玻璃，分三档实现，从下往上
档 1（无 GPU / 不支持）：纯色 + 描边，必须已经能看。
档 2（API 31+）：底部栏背后内容做模糊——整页快照挂 graphicsLayer.renderEffect，
  或用现成 backdrop-blur 方案；半径 28dp，tint 0.75。
档 3（API 33+，AGSL）：在档 2 的模糊层上加边缘折射：
  refraction 0.42、edgeBand 14dp、rim 1.6dp、rimHighlight 0.16；
  只让靠近边缘的窄带参与（(1-depth)² 权重），中间保持毛玻璃；
  开启后 tint 降到 0.48/0.56，edge 0.07。

第三步：开关
- 设置 → 外观 增加「液态玻璃」开关，默认关，持久化。
- 可用条件：SDK >= 33、非省电模式、非低内存设备；不满足时开关置灰并写明原因。
- 渲染失败或掉帧时自动回落到档 2，不允许崩溃。

验收
- 三个 tab 文案正确，选中态在旋转/进程重建后保留。
- 关开关 = 档 2 毛玻璃；设备不支持 = 开关灰 + 原因文案。
- 切 tab 不重建页面，滚动位置保留。
- 手势条不压 tab，可点区域 ≥ 48dp。
- 滚动/拖拽时没有每帧重建 RenderEffect，60fps 不掉帧。
```

## 2 一句话版（先看方向）

```text
读 docs/liquid-glass-notes.md 和 docs/ui-notes.md。先只做第一步：
把底部改成书架/书签/设置三项的胶囊浮层（64dp 高、16dp 边距、纯色 fallback），
不写模糊，不写 shader。给我方案和文件改动清单。
```

## 3 为什么这么拆

- 先结构后玻璃：胶囊没立住就上 shader，最后尺寸、边距、描边全是散的。
- 档 1 必须有：低端机和 API < 31 的用户占不少，没模糊也要像样。
- 液态单独一档：它只加在边缘窄带，做砸了最多是「边上一圈糊」，不会毁整页。
- 开关要带原因：只置灰不给理由，用户会以为是 bug。

## 4 容易翻车的地方

- **Insets**：`navigationBars` 没处理，胶囊会被手势条压住或浮太高。
- **每帧重建 effect**：把 `RenderEffect` 放在 `remember` 之外或按帧 new，
  会直接掉到 20fps；要把半径、区域 uniform 缓存住。
- **整页快照太贵**：别对每个页面都做；只对底部栏覆盖的条带做，或降采样。
- **状态丢失**：tab 切换用 `NavHost` 时记得 `saveState/restoreState`，
  否则书架滚动位置每次归零。
- **和 mini player 打架**：两者都浮在底部，先定层级与间距，再调玻璃参数。
- **液态和浅色背景**：亮色下 tint 0.56 仍可能不够，先在真实壁纸上试。

## 5 验收时看什么

1. 关掉玻璃开关，底部是否仍然好看、可读。
2. 打开开关，滚动列表时底部是否跟着内容一起虚化（不是只糊壁纸）。
3. 省电模式/低端机上，开关是否自动灰掉。
4. 连续切 20 次 tab，有没有掉帧或内存上涨。
