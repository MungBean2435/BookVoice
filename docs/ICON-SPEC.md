# 书声 / BookVoice 图标交付规范

给画图的人（或 AI）用：照着这份做，产出直接能进 Android 工程。

## 1. 交付物（必须）

| 文件 | 尺寸 | 格式 | 要求 |
| --- | --- | --- | --- |
| `icon.svg` | viewBox `0 0 108 108` | SVG 纯矢量 | 透明背景，图形即图标轮廓 |
| `icon-1024.png` | 1024×1024 | PNG RGBA | 从上面的 SVG 导出，背景透明 |
| `icon-512.png` | 512×512 | PNG RGBA | 同上 |

只给 `icon.svg` 也行 —— 其余尺寸我用 `assets/icon/build_icons.py` + `rsvg-convert` 自动生成（需要 `apt install librsvg2-bin`）。

## 2. 完整尺寸表（我这边脚本会生成，供核对）

自适应图标前景层（108dp 画布）：

| 密度 | 像素 |
| --- | --- |
| mdpi | 108×108 |
| hdpi | 162×162 |
| xhdpi | 216×216 |
| xxhdpi | 324×324 |
| xxxhdpi | 432×432 |

- 自适应背景层：同尺寸，**全透明**（图标轮廓就是画面里的主体，不要自己垫深色圆底/方底）。
- 传统启动器图标（48dp）：mdpi 48、hdpi 72、xhdpi 96、xxhdpi 144、xxxhdpi 192，PNG RGBA。
- 可选（Android 13+ 主题图标）：108dp 单色剪影，透明背景，只用 `#000000`。

## 3. 布局硬约束

- 画布固定 108×108；主体（书页 + 声波）外接框放在**中心 66×66** 以内，最坏情况是圆形遮罩裁切（半径 33），超出会被切。
- 每边至少留 18dp 空白，否则圆角方形/圆形遮罩会啃掉尖角。
- 背景透明，不要深色底板 —— 之前的深色渐变在深色桌面上会显示成一圈黑边。
- 不放文字、不放细线（线宽 ≥ 2dp，否则缩到 48dp 会消失）。
- 最小可辨识测试：缩到 48×48 仍能一眼看出「书页 + 声波」。

## 4. 现有视觉（可作为重画基准）

- 书页：圆角矩形 52×60（圆角 10），右上角切掉 16 作折角；纸色 `#F5EBD8`，折角面 `#CDBA9A`，折痕 `#B09C7C`，外轮廓描边 `#D8C7A8`（0.8dp）。
- 声波：横向 `x 34→74`，中线 `y 53`，振幅 10.5，3.4 个周期，线宽 5.2，圆头圆角连接，两端用 `sin(πt)^0.55` 收窄；颜色 `#E9A43E`。
- 整体：透明底，无外框，无阴影。

## 5. 验收

- 贴到浅色、深色、纯白三种桌面背景上都能看清轮廓。
- 圆形、圆角方形两种遮罩下主体不被切。
- 48dp 下不糊。

## 6. 交付方式

把 SVG / PNG 给我，或直接覆盖 `assets/icon/` 下的文件，我跑一遍
`python3 assets/icon/build_icons.py` 再重建 APK。
