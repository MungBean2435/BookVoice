# 书声 / BookVoice 图标交付规范

给画图的人（或 AI）用：照着这份做，产出直接能进 Android 工程。

## 1. 先说结论：主体要铺满整块画布

Android 自适应图标会被桌面切成圆形 / 圆角方形。**画布里留空的透明区域不会保持透明**——桌面会用黑色或它自己的底板填上（之前就出现过一圈黑边）。

所以图标要做成「一整块方形的画面」，颜色铺满画布，靠遮罩决定最终形状：

- 底色（米白 `#F5EBD8`）铺满整个 108×108，不要留透明边；
- 图形元素（声波、折角）画在这块底色之上；
- 不要把图形画成一个小方块浮在透明背景上。

## 2. 交付物

| 文件 | 尺寸 | 格式 | 要求 |
| --- | --- | --- | --- |
| `icon.svg` | viewBox `0 0 108 108` | SVG 纯矢量 | 底色铺满画布，右上角圆角 22 |
| `icon-1024.png` | 1024×1024 | PNG | 从上面的 SVG 导出 |
| `icon-512.png` | 512×512 | PNG | 同上 |

只给 `icon.svg` 也可以，其余尺寸我用 `assets/icon/build_icons.py` + `rsvg-convert` 生成（`apt install librsvg2-bin`）。

## 3. 画布与安全区（108×108 设计空间）

- 画布固定 `108×108`，图形按 108 坐标画，任何分辨率都由脚本缩放。
- 关键内容（声波、折角的视觉重心）放在**中心 66×66** 内：圆形遮罩半径 33，超出的部分会被切掉。
- 每边至少留 18dp 让圆角方形/圆形遮罩有裁切余量；底色本身要画到画布外沿（0 到 108），否则又会露出黑色。

## 4. 现在的视觉（可作为重画基准，也可以整套换掉）

- 底色：米白 `#F5EBD8`，铺满画布，右上角折角。
- 折角：从 `(84, 0)` 到 `(108, 24)` 的三角，填充 `#CDBA9A`，折痕线 `#B09C7C`（1dp）。
- 声波：中心 `(54, 56)`，横向半宽 23，振幅 11.8，3.4 个周期，线宽 5.6，圆头圆角连接，两端用 `sin(πt)^0.55` 收窄，颜色 `#E9A43E`。
- 外轮廓：`#E6D7BA`，0.9dp（只在独立图标里有，启动器图层里不需要）。

## 6. 验收

- 贴到浅色、深色、纯白三种桌面背景上都不出现黑边、白边。
- 圆形、圆角方形两种遮罩下，声波和折角都完整。
- 缩到 48×48 仍能认出「声波」。
- 不放文字，线宽 ≥ 2dp。

## 7. 交付方式

把 SVG / PNG 给我，或直接覆盖 `assets/icon/` 下的文件，我跑一遍
`python3 assets/icon/build_icons.py` 再重建 APK。
